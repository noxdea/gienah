A smaller blast radius.

Gienah keeps extension code outside the host process and checks declared capabilities before a plugin can call application methods.

Process isolation

Run plugin entrypoints as child processes connected through bounded framed messages.

Capability gates

Reject unknown declarations and deny host methods until the matching capability is granted.

Lifecycle control

Discover manifests, activate on a named reason, make timeout-aware calls, and shut down cleanly.

Host a plugin.

Expose only application-specific methods, then activate manifests when their reason occurs.

Ruby
$ bundle add gienah

host = Gienah::Host.new(api_version: 1)
host.expose("workspace/notify") { |params|
  puts params.fetch("message")
}
host.discover(["plugins"])
host.activate("example", reason: "onStartup")
